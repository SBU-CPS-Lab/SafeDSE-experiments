# Environment of the experiments

All runs were made on one machine. Timing rows of different experiments are
comparable; other machines will give other times.

## Machine
host: shaniaki-rog
os: Linux 7.0.0-34-generic x86_64 (Ubuntu)
CPU(s):                                  8
Model name:                              Intel(R) Core(TM) i7-7700HQ CPU @ 2.80GHz
Thread(s) per core:                      2
NUMA node0 CPU(s):                       0-7
Memory (/proc/meminfo): MemTotal 16252596 kB (15.5 GiB), SwapTotal 33554428 kB.
  The desktop session shared this memory; peak memory of the compiler per
  instance is in e3_flat.csv (max_rss_mb, /usr/bin/time %M).

## MiniZinc
MiniZinc to FlatZinc converter, version 2.10.1, build 33348285743
(snap package; bootstrap_minizinc.sh of SafeDSE installs the same bundle)

Available solver configurations:
  Chuffed 0.14.0 (org.chuffed.chuffed, cp, lcg, int)
  COIN-BC 2.10.13/1.17.11 (org.minizinc.mip.coin-bc, mip, float, api, osicbc, coinbc, cbc)
  CPLEX <unknown version> (org.minizinc.mip.cplex, mip, float, api)
  findMUS 2.10.1 (org.minizinc.findmus)
  Gecode 6.4.0 (org.gecode.gecode, default solver, cp, int, float, set, restart)
  Gecode Gist 6.4.0 (org.gecode.gist, cp, int, float, set, restart)
  Globalizer 0.1.8 (org.minizinc.globalizer, experimental, tool)
  Gurobi <unknown version> (org.minizinc.mip.gurobi, mip, float, api)
  HiGHS 1.15.1 (org.minizinc.mip.highs, mip, float, api, highs)
  OR Tools 9.7.2996 (com.google.or-tools, ortools, cp, lcg, int)
  OR Tools CP-SAT 9.15 (cp-sat, cp-sat, cp, lcg, int)
  SCIP <unknown version> (org.minizinc.mip.scip, mip, float, api)
  Xpress <unknown version> (org.minizinc.mip.xpress, mip, float, api, float_times)

Experiments use OR Tools CP-SAT 9.15 via MiniZinc with 4 workers
(-p 4 plus --fzn-flags "--params num_workers:4"), a time limit of 300 s per
solve (RQ1, RQ2, RQ4), and 600 s per cost solve and 300 s per mu* solve
(RQ3). Every non-THROUGHPUT solution passes exact_period.py (design fixed, mu
minimised) before tools/verify.py. e4_xsolver.csv also used Gecode 6.4.0,
Chuffed 0.14.0 and HiGHS 1.15.1 with one thread each, and CP-SAT with one
worker.

## SafeDSE
The model (model/, lib/) is the same in every SafeDSE commit used for the
reported rows (unchanged since commit 0e9cf41; later commits changed comments
only). Rows were produced with the front end, verifier and generator of
commits 3cd0d54 (RQ1) to 1c23d7c; tools/ and data/ changes in that range were
followed by re-runs of the affected rows. Commit 1c23d7c is the content of
release v1.0.0 without its documentation and comment changes.
